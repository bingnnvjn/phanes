# Security policy

`renderer` crosses Rust, JNI, FreeType, wgpu, native code, and embedded
font assets. Treat memory-safety, FFI, dependency, and asset-provenance
reports as security-sensitive.

Report suspected vulnerabilities privately to the repository maintainers.
Include the affected commit, target/platform, minimal reproduction, and
impact. Do not include tokens, private keys, keystores, device identifiers,
or confidential logs.

Until a public remote and security contact are recorded, this file is a
publication baseline; no public disclosure channel is implied.
