# ADR-0002: v1 最小集定义（工单 04 交付范围）

- 状态：已确认（2026-08-06，用户逐项拍板）
- 日期：2026-08-06
- 范围：与 spec 用户故事 8/15 及工单 04 一致；逐项可勾选验收，不得蔓延

## 决策

v1 "什么算做完"的清单如下。勾选项同时是工单 04 的验收标准（用户可逐项打勾）。

## 0. 红线回归（不破坏既有行为）

- [ ] 打开即终端：点击 Fable 图标直接进入终端，无首页/引导页（launcher 直连 TermuxActivity）。
- [ ] 会话层底盘不动：PTY/进程/环境/前台服务逻辑不改。
- [ ] 终端 I/O 与基本交互回归：echo/pwd/ls 正常；滚动、方向键、复制粘贴、长按菜单可用
  （缝 1 行为验收 + 真机手测）。

## 1. 字号（spec 故事 15）

- [ ] 设置页提供字号调节（范围 8–24，滑块或数值），改动立即生效（复用现有
  `KEY_FONTSIZE` → `setTextSize` 钩子）。
- [ ] 字号持久化：重启 App 后保持。
- [ ] 双指缩放字号（现有手势）回归保持。

## 2. 主题（spec 故事 15）

- [ ] 界面外壳（设置页/工具栏/抽屉/状态栏）主题模式三选一：跟随系统 / 浅色 / 深色
  （默认跟随系统；复用现有 `NightMode`/DayNight 机制，04 只需加设置项）。
- [ ] 终端配色优先加载 `~/.termux/colors.properties`（迁移用户的配色不丢）；
  无该文件时使用内置默认配色（明/暗各一套，随系统明暗走）。
- [ ] 有 `colors.properties` 时终端色以它为准、不随系统明暗切换（明确边界，避免误解）。

## 3. 键盘布局（spec 故事 15）

- [ ] 扩展键行（Extra Keys）默认布局可用（ESC/TAB/CTRL/ALT/方向键等，沿用现有默认值）。
- [ ] `termux.properties` 的 `extra-keys` 配置生效（既有机制回归）。
- [ ] 软键盘开关与"仅无硬件键盘时启用"开关可用（既有回归）。

## 4. 会话（spec 故事 7/8）

- [ ] 多会话：新建/切换/关闭（既有行为回归）。
- [ ] 会话恢复（已定稿：方案 B）：冷启动自动建立默认 shell 会话；App 进程存活期间，
  Activity 重建/旋转/切后台返回时会话不丢（前台服务持有）。
- [ ] 会话列表持久化最近会话记录（时间/工作目录）；进程被杀后可一键重开
  （新 shell 进入该工作目录；目录已失效时回退 `$HOME`）。
  （边界：PTY 进程是 App 子进程，进程被杀后无法复活旧 shell，B 是"按上次位置重开"。）

## 5. 设置入口

- [ ] 设置页只保留终端相关项，移除 Termux API/Boot/Float/Tasker/Widget 配套 App 设置入口
  （用户确认；与 spec"不依赖配套 App"一致）。
- [ ] 保留"调试"（日志级别/崩溃通知）与"关于"；"关于"内容在 04 改造：去掉 Termux 官方链接与
  配套插件信息，只留 Fable 版本/设备信息（可加 Fable 自己的链接）。

## 6. 界面中文化（用户新增要求）

- [ ] 全部 App 自有界面文案原生支持简体中文（跟随系统语言：系统中文显示中文、系统英文显示英文）。
- [ ] 翻译范围：app + termux-shared + terminal-view 约 165 条资源文案，外加代码中硬编码英文
  （关于页生成内容、提示、通知等）；不翻译终端内 shell 输出（属 Linux 环境文本）。
- [ ] 不加"界面语言"手动选项（用户确认不需要）。

## 明确不做（防蔓延）

- AI 面板/工作台入口、服务管理、环境切换器、现代渲染核心（rio-vt/CoreAdapter）、HUD 交互语言、
 迁移触发形态（工单 02）、Android 15 权限与 SDK 升级（工单 05）、包名/签名（已由工单 01 闭环）。
- 界面语言手动选项（跟随系统即可）、终端主题皮肤商店、终端色随系统明暗自动切换（有自定义配色时）。
