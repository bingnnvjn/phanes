# Triage 标签

技能用规范角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

## 分类角色（每个 issue 恰一个）

| 技能里的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `bug` | `bug` | 坏了的东西 |
| `enhancement` | `enhancement` | 新功能或改进 |

## 状态角色（每个 issue 恰一个）

| 技能里的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待分类` | 维护者需要评估这个 issue |
| `needs-info` | `待补充信息` | 等报告人补充更多信息 |
| `ready-for-agent` | `待Agent处理` | 描述完整，可交给 AFK agent |
| `ready-for-human` | `待人工处理` | 需要人工实现 |
| `wontfix` | `不修复` | 决定不处理 |

注意：`triage` 只用于外部来单/原始问题；`/to-tickets` 产出的工单已 agent-ready，不 triage。工单运行状态词汇见 `issue-tracker.md`（待开工/进行中/待验收/已完成/挂起）。

要改词汇就编辑右列。
