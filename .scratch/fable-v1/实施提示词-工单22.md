关键提示：

- **sbix 通路**：新增 Rust 解析 sbix 表（strike 选择、dupe 记录、`originOffsetX/Y`、graphic type `png `），用现有 `png` crate 解码；沿用 `colr.rs` 的自解析先例；不重开 FreeType PNG、不新增 C 依赖。
- **恒 160 超采样**：解码 160 档 → 按目标尺寸缩放（双线性 + 线性空间 gamma 校正）→ 放入格子；字号 >160px 用 160 原图放大。
- **字体资产**：剥离产物（face 0、仅 160 档）已预生成并记录 sha256；最终由构建脚本从固定 URL 下载原始 ttc → 剥离 → 校验（版本/160 档/3761 PNG/36 样例），产物进 fable-app assets（noCompress）。
- **assets 加载**：fable-app 新增 assets 目录与 JNI 传字体入口（fd/路径，Rust 侧 mmap）；宿主/Termux 自检走文件路径；加载失败自动降级 Noto；诊断输出字体版本 + 加载状态。
- **回退**：Apple 无图 → Noto COLRv1（FreeType/colr.rs 通路保留）→ 主题适配方框；以完整 cluster 为单位；输出 Apple vs Noto 覆盖差异报告。

- **性能**：首现 ≤50ms / 加载 ≤200ms / 预热 50 个热门（2s 内）/ 缓存 512 张 LRU；每完成一项跑一次回归（`cargo run --release` 软件光栅 ALL PASS + APK 构建），避免积到最后。

## 已定决策（禁止重新调研/讨论）

- 字体 = Apple Color Emoji `21.4d3e1`（PoomSmart `17.0.0-apple` 提取版，原版位图；**只保留 160px 档**，40/64/96 删除，图样零删减）
- 清晰度 = 恒 160 超采样；>160px 用 160 原图放大；双线性 + 线性空间缩放起步
- 解码 = Rust 自解析 sbix + png crate（不加 C 依赖）；rustybuzz 整形照旧
- 打包 = Apple 与 Noto 均改 APK assets（noCompress、mmap）；sha256/版本校验；失败降级 Noto
- 回退 = Apple → Noto COLRv1 → 方框；以完整 cluster 为单位
- 布局 = 原生比例、2 格、垂直居中、非透明包围盒视觉居中、行高稳定
- 指标 = 首现 ≤50ms、加载 ≤200ms、预热 50 个（2s 内）、缓存 512 LRU
- 更新 = 溯源文件 + 换字体步骤 + 上游自动检查（每周）
- 验收 = 类别化离屏自动化 + 真机主观（两档尺寸/字号 12–48/深浅主题/对比图/RTL/深色边缘/选中滚动）+ 工单 13 回归 + 诊断输出字体版本/状态

## 环境快照（2026-08-10 核实）

- 仓库：根（`$HOME/CODEX/Fable`）、spike-render（独立 git 仓库）、fable-app（独立 git 仓库，.so 落 `app/src/main/jniLibs/arm64-v8a/libfable-render.so`）
- 构建：`cd spike-render && cargo run --release`（宿主自检/离屏断言）；APK：`cd fable-app && export JAVA_HOME=/data/data/com.termux/files/usr/lib/jvm/java-25-openjdk && ./gradlew :app:assembleDebug`
- 产物校验：aapt2 badging（`com.gph.fable`）/ apksigner / `unzip -l` 查 .so / assets 清单（noCompress 确认）
- 工具链：rustc 1.97.1 + rust-std-aarch64-linux-android；Termux clang 21.1.8（默认 target `aarch64-unknown-linux-android24`）；宿主 freetype 2.14.3 + harfbuzz 14.2（离屏参照）
- 现有彩色通路：`spike-render/src/emoji.rs`（include_bytes 内嵌 `assets/NotoColorEmoji.ttf`，COLRv1）+ `colr.rs`（FreeType paint graph 合成）+ rustybuzz 0.20.1；FreeType 构建关 `FT_CONFIG_OPTION_USE_PNG`
- JNI 桥：fable-app `RenderCore.java`（rendererCreate 等；**无传字体入口，本单新增**）；fable-app 目前**无 assets 目录**
- 字体事实：原始 ttc `AppleColorEmoji-160px.ttc` 63,888,516B，sha256 前 24 位 `76c37f95960d82a37a2c93c9`，版本 `21.4d3e1`，4367 glyphs，strikes 40/64/96/160（160 档 3761 PNG）；剥离产物（face 0 仅 160 档）30,770,720B，sha256 前 24 位 `e7605cad9802272292e9d6cd`；下载源 `https://ghfast.top/https://github.com/PoomSmart/EmojiFonts/releases/download/17.0.0-apple/AppleColorEmoji-160px.ttc`
- 网络：GitHub 直连慢/不稳，用 `ghfast.top` 前缀；本环境 `rg` 不可用，用 `grep`/`find`；`/tmp` 部分不可写，临时文件放仓库内路径；禁 `rm -f`（用 unlink/find -delete）；curl 管道给解释器会被拦截（先下载到文件再解析）
- 真机验收：RenderActivity 探针（[emoji]/[box]/[u-line] 按钮）；APK 复制到 `~/storage/downloads/` 交用户安装（<厂商 ROM> 拦 `pm install`）
