# 41 — 签名凭据外置与调试身份隔离

**What to build:** 把 Android 签名凭据移出仓库源码，通过本机或 CI secret 注入；release 继续使用长期发布身份，debug 默认使用独立调试身份；保留显式的本地覆盖方式，避免破坏正式包的覆盖升级能力。

**Blocked by:** None
Status: 已完成

## 验收清单

- [x] Gradle 文件不包含 keystore 密码、私钥或其他签名 secret
- [x] release 构建缺少凭据时明确失败，不静默使用 debug key
- [x] debug 默认不使用 release key；需要覆盖已装正式包时有显式、本地且不入库的开关
- [x] secret/keystore 扫描命令 PASS，历史泄露处置建议写入 Comments
- [x] debug 与 release 构建配置测试或程序化检查通过
