# 26 — 双实现并行 + 切换开关（CoreAdapter 缝上的会话层抽象）

**What to build:** 在 CoreAdapter 缝上把会话层抽象为 Java 接口（会话工厂/会话句柄），Java 会话层（现状）与 Rust 会话层（fable-v1/25 产物）双实现平级；切换开关 = 构建期默认 Rust + 设置页 debug 项可切回 Java（持久化）；主终端在 Rust 会话层上跑通（打开即终端、输入输出、多会话、滚动、复制粘贴、会话恢复）；Java 会话层原样保留、零回归。

**Blocked by:** fable-v1/25
Status: 待开工
