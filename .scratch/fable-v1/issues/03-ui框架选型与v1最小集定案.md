### 选型结论：v1 采用 XML/经典 View，不引入 Compose（推翻"倾向 Compose"）

证据（均为本机实证或官方文档）：

1. **代码库**：全仓纯 Java、0 个 .kt；UI 全部 XML + 经典 View；TerminalView 已在 `activity_termux.xml` 直接布局。Compose 必须引入 Kotlin 工具链（composable 只能 Kotlin 编写，官方文档）。
2. **构建链实证（临时分支最小验证，未提交、已还原、构建链恢复验证通过）**：
   - Compose 1.0.5 + Kotlin 1.5.31（compileSdk 30 下唯一可用组合，官方兼容表 1.0.5↔1.5.31）：`:app:compileDebugKotlin` 失败——Kotlin 1.5.31 编译器在 JDK 17 抛 `InaccessibleObjectException: java.base does not "opens java.util"`；in-process 与 `kotlin.daemon.jvmargs` 加 `--add-opens` 均无效。
   - Compose 1.1.1 + Kotlin 1.6.10（官方兼容表 1.1.1↔1.6.10）：`checkDebugAarMetadata` 硬失败——`material:1.1.1` 要求 minCompileSdk 31 > 当前 compileSdk 30。
   - 官方兼容表：Kotlin 2.x 要求 Gradle ≥ 7.6.3（当前 7.2）；现代 Compose（1.12）要求 compileSdk 37 + AGP 9.2。采用 Compose 必须先升级 Gradle+AGP+compileSdk 整链，本机还缺 platforms 31–33。
3. **网络**：google() 实际仓库 dl.google.com 可达（Compose/Kotlin 依赖可下载，非阻塞项）；Maven Central 可达。
4. **风险**：XML 路径直接复用已调通 UI（含 IME/Gboard 等多年修复），v1 最小 UI 面小，重写收益低、回归风险高。

### v1 最小集（草稿，待用户确认）

0. 红线回归：打开即终端 / 会话层不动 / I/O+基本交互回归。
1. 字号：设置可调（8–24）即时生效、持久化、双指缩放回归。
2. 主题：内置明/暗跟随系统+手动覆盖，作用于终端与工具栏，保留 colors.properties 加载。
3. 键盘布局：默认扩展键行可用、extra-keys 配置生效、软键盘开关回归。
4. 会话：多会话回归；会话恢复二选一——A（最小）：冷启动自动建默认会话 + 进程存活期间 Activity 重建不丢；B（增强）：A + 最近会话记录（时间/工作目录）可一键重开。
5. 设置入口：只留终端相关项，移除 Termux 配套 App（API/Boot/Float/Tasker/Widget）设置入口。
