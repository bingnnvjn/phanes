**1. 接线方式**

- CoreAdapter 缝定案：`terminal-emulator/.../adapter/CoreAdapter.java`（Java 接口：write/resize/scroll/setSelection/getSelectionText/setFontSize/getCellSize/setPalette/resetPalette/attach/detach/render/reset/destroy + 能力清单）。旧路径 `TerminalEmulatorCoreAdapter`（包 TerminalEmulator，渲染能力声明不支持）与新路径 `FableRenderCoreAdapter`（app 模块，走 RenderCore JNI → 每会话渲染线程 mailbox，工单 12/14 产物）均实现该缝；主终端 UI/会话接线只依赖接口。
- 主终端切换：`activity_termux.xml` 顶层改为 `FableTerminalView`（每会话一个 fable-render 适配器 + 一个 SurfaceView，参照工单 10/12 探针结构），内嵌 `FableInputTerminalView`（terminal-view 模块，继承 TerminalView）继续承担 IME/手势/滚动/长按选择/上下文菜单，但不再绘制正文（isOpaque 与 onDraw 按缝绑定切换）。TerminalView/TerminalEmulator 旧路径保留不删，适配器无效时自动降级旧路径。
- 字节管道：`TerminalSession` 的 reader→main handler 交付点经 `mCoreAdapter.write()` 喂核心（PTY/进程/环境/生命周期逻辑未动）；resize 走 `updateSize()` 同时下发 PTY winsize/旧 emulator/缝。新增缝接入前字节环形缓冲（1MB）回放：冷启动 prompt / Activity 重建后重挂已有会话时，attach 前已输出的字节先回放进核心，避免"打开空白直到新输出"。
- 双向同步：滚动 = `FableInputTerminalView.onDraw → syncAdapterState → adapter.scroll(delta)`；选择 overlay 按**视口相对行**（0 = 视口顶行，回看为负）同步到核心（与 TerminalBuffer 外部坐标同约定），`getSelectionText` 走缝 API（工单 14）；字号 = `setTextSize → adapter.setFontSize + getCellSize 重排`。
- 生命周期：旋转（activity configChanges 自持）/切后台只 detach 不 destroy，适配器留在会话上（字节不丢）；会话关闭 `onSessionRemoved → adapter.destroy`；进程退出 `cleanupResources → adapter.destroy`（幂等）。

**3. 坑与解法**

- **编译错误（收尾编辑遗留）**：`TextSelectionCursorController.getSelectedText()` 曾改调 `terminalView.getSelectedText()` → 与 `TerminalView.getSelectedText()` 互调无限递归（选择激活即 UI 线程 StackOverflow）。改为子类可覆盖的 `getCoreSelectionText()`（旧路径返回 null，新路径返回缝文本）+ 空时回退 `mEmulator.getSelectedText` 直读，断开递归；`TextSelectionCursorController` 与 `TerminalView` 跨包，方法必须 public。
- **滚动回看选择坐标不一致**：初始实现把屏幕行直接当核心行传，回看时 transcript 行（负 mSelY）被钳到 0，选择错位/取错行。定案缝约定"视口相对行"，旧路径读取时换算 `externalRow = viewportRow + mTopRow`（TerminalBuffer 外部坐标），新路径与渲染器 snapshot 行序对齐；JVM + instrumentation 双侧断言覆盖。
- **冷启动丢字节**：adapter 在 view attach 时才建立，进程先行输出（prompt/motd）不进核心 → 空白视图。加 1MB 环形缓冲在缝接入前收集、setCoreAdapter 时回放（只收 `mCoreAdapter == null` 期间，避免旋转重挂重复写）。
- **attach 顺序**：`FableTerminalView.attachSession` 先绑缝再 attachSession 会让 setCoreAdapter 的 updateSize 把仍挂着的旧会话 PTY 临时 resize；改为先 `inputView.attachSession(session)` 再绑缝。
- **TLS 对齐 / dlopen IE 模型（工单 10 坑 F）**：未动 spike 资产与 TLS 处理，产物复验保持 p_align=0x40。
