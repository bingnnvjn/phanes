**2. 踩过的坑与解法**

- **删除边界确认**：鼠标事件编码（X10/SGR）旧实现读旧模拟器 DECSET 位（1006/1002）→ 补缝 mode 查询 `getModeMouseSgr` / `getModeMouseButtonEvent`，编码逻辑迁到 `TerminalSession.encodeMouseEvent`（与旧 `sendMouseEvent` 逐字节一致，含越界钳制与 8-bit 限制）。
- **词边界/URL/转录的旧屏幕直读**：`TextSelectionCursorController` 词边界展开、`TermuxTerminalViewClient` URL 取词、`ShellUtils` 转录都依赖旧模拟器内容 → 补缝 `getText` / `getWordBoundsAt` / `getWordAt` / `getTranscriptText`；Rust 侧经 `ghostty_terminal_grid_ref`（SCREEN 坐标）逐格读字素，软换行续行用 `ROW_DATA_WRAP_CONTINUATION` 还原整行语义。
- **离屏断言首跑失败**：mailbox_checks 里已有 3 行内容后再写 15 行，scrollback=9 而非 6（核心含当前空行，与旧模拟器 transcript 语义一致）；断言按真实语义修正，行为无需改。
- **aapt2 校验**：官方 android-sdk 的 aapt2 是 x86_64 不能在本机跑，沿用项目既有 Termux 原生 aapt2（`aapt2 dump badging` 确认包名/versionCode）。
- **fake core 词边界实现慢循环**：初版用 `Integer.MAX_VALUE` 做端界导致 2^31 次空循环（能跑完但极慢），改为按行长度钳制。
- **宽字符列偏移近似**：`getWordAt`/转录的列→字节偏移按整行文本长度累计（与旧 TerminalBuffer 的按列累计同为近似），ASCII/URL 场景一致，宽字符边角由真机回归（工单 40）兜底。

**3. 结论写回（对后续工单/决策的输入）**

- **删除清单**：`terminal-emulator` 的 TerminalEmulator / TerminalBuffer / TerminalRow / TextStyle / TerminalColors / TerminalColorScheme / WcWidth / TerminalOutput / `adapter.TerminalEmulatorCoreAdapter`；`terminal-view` 的 TerminalRenderer；旧模拟器 17 个测试文件（139 个 JUnit3 行为测试方法随删不迁移）。
- **TerminalSession 不再创建模拟器**：`updateSize` 只建 Rust 会话后端（`initializeSession`）；字节只进 CoreAdapter（未接缝时 1MB 环形缓冲回放）；标题/铃/模式/选择/滚动/光标/转录全部走缝；旧路径（`mCoreAdapter == null`）回退分支一并删除。
- **新测试集 = 18 个 JVM 缝契约测试**（fake in-memory 核心 + KeyHandler + 会话层缝），核心行为由 Rust 20 单测 + 双离屏自检 + 真机（工单 40）兜底，符合 ADR-0009 决策 7。
- **行为注意点（建议单独工单/决策确认）**：OSC 52 剪贴板写入与 OSC 颜色变更的旧回调来源随模拟器删除而消失——新核心未注册 clipboard effect 回调，需要时给 CoreAdapter 补剪贴板回调；`onColorsChanged` 通知源同失（新路径配色走 `FableTerminalPalette` push，本就不读 OSC 动态色）。
- **对工单 32（清理探针与死代码）**：fable-core 模块现只剩缝相关类（CoreAdapter / FableSession 族 / TerminalSession / KeyHandler / Logger / TerminalSessionClient）；可顺手清 `TerminalSession` 遗留的 `mTranscriptRows` 字段与 `write(String)` 便利方法（现保留以最小化调用面）。
