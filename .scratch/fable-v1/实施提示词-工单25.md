## 已定决策（禁止重新调研/讨论）

- 范围：PTY 生命周期（spawn/close/resize）、进程管理、环境注入、字节 I/O 全进 Rust；Java 壳只保留 UI/设置/系统集成
- 零件：portable-pty 0.9.0（fable-v1/24 判定为准）；nix 兜底仅在 fable-v1/24 结论要求时使用
- 并发指标：2–4 会话硬指标、8 并发设计余量（压测记录 8 会话数据）
- 事件流第一版最小集六事件：command_started / output_chunk / command_finished / exit_code / session_created / session_closed；schema 含 session_id、时间戳、扩展 metadata
- 环境注入：环境快照由 Kotlin 计算传入 Rust，不重实现 AndroidShellEnvironment / termux-shared 环境组装
- JNI 边界：SessionHandle（创建/读写/resize/close）+ 事件回调 + 诊断日志订阅；Kotlin 第一版只接诊断/日志
