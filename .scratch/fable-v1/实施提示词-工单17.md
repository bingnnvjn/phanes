## 已定决策（禁止重新调研/讨论）

- Fable 包仓库 = 扁平 apt 仓库，托管于 fable-bootstrap 的 GitHub Releases；Fable 侧 sources.list 指向固定 stable tag `releases/download/fable-repo-current/`（避免同仓 bootstrap Release 改变 GitHub `latest`）
- GPG 签名：自签、ed25519（实施时复验 gpgv 兼容，必要时回退 rsa4096）；**私钥只存 GitHub Actions secret，CI 构建后自动签名**；公钥提交进仓库
- 更新流 = 按需构建：workflow_dispatch 输入包名 → build-package.sh（含依赖闭包）→ 合并 debs → 生成 Packages/Packages.gz + Release/InRelease → 发布全量快照 Release；加 actions/cache 增量
- bootstrap 全量重建流程保留不动（后置）
- 首批清单 21 个（2026-08-09 定稿，见工单）
- 顺序：本单（仓库端）→ 工单 18（Fable 环境接入）；不阻塞工单 02 Phase B（用户可先跑迁移）
