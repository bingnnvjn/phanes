## 实施纪律

- feature 类工单。先为一个 FFI/unsafe 边界补回归测试或可执行断言，再收紧对应 lint。
- 每次只处理一个安全边界。不要用全局 `allow` 换取临时绿灯。

## 已定决策

- renderer = Rust + wgpu，核心 = libghostty-vt；不替换渲染路线或 ABI
- `unsafe` 的目标是缩小、写清前提、由安全 API 包装，不是机械消灭关键字
- 公开 Rust crate 必须通过全目标严格 lint，见 ADR-0010
