## 工单任务

按工单 12 验收清单逐项执行。关键提示：

- **① 脏行增量顶点**：现状是全量重建顶点；目标 = 只重建脏行对应顶点并增量上传（RenderState 的 Dirty::Partial + 每行 dirty 已在 09 验证）。记录 seq200 流式下 CPU 耗时对比。
- **② 彩色 emoji**：fontdue 只有灰度；参照官方"灰度/彩色双图集"——彩色字形（emoji）需另走彩色光栅（如系统彩色字体/图片字形）进彩色图集，shader 按 mode 采样不同图集。离屏 PNG 与真机都要出彩色。
- **③ sprite face**：把边框线/下划线/光标/盲文等改成程序化自绘进灰度图集（官方 z2d 思路），不依赖字体覆盖。
- **④ 渲染线程**：从"Kotlin 内容签名触发同步渲染"改为独立渲染线程 + mailbox（参考官方 Thread.zig 的 demand lock 思路：渲染线程要锁时让 I/O 让路）；多会话各自独立；验收重点是 UI 不阻塞、快速输出不掉帧。
- 每完成一项跑一次回归（cargo run --release 软件光栅 ALL PASS + APK 构建），避免积到最后。
