## 工单任务

把 fork 的包名从 `com.termux` 全部改为 `com.gph.fable`：

- `applicationId`、manifest `package`、manifest 占位符（`TERMUX_PACKAGE_NAME`，驱动 sharedUserId、provider authorities、RUN_COMMAND 权限名等）
- Java 包名与代码内全部引用（当前约 182 个文件含 com.termux）
- 生成个人 keystore 并配置签名（debug 与 release 共用该身份）
- 保持构建通过，用三条命令校验产物：`aapt2 dump badging`（包名/版本）、`apksigner verify`（签名）、APK 内容清单（arm64 原生库存在）
- 改包名后保持 bootstrap 变体（apt-android-7）与代码内 PackageVariant 一致，避免启动崩溃

## 构建环境

- 构建目录：`fable-app/`（在项目根目录下）
