## 工单任务

按工单 15 验收清单逐项执行；每项给出 PASS/FAIL 或验证数据。关键提示：

- **CoreAdapter 缝**：定义 UI/会话接线只依赖的缝接口（喂字节/resize/滚动/选择/取选中文本/attach/detach/渲染驱动/能力清单）；旧路径（TerminalEmulator）与新路径（fable-render，经工单 14 API）都实现该缝。主终端走新路径。

- **交互**：IME/扩展键输入、滚动、双指缩放、长按选择/复制（工单 14 选中文本 API）、粘贴、上下文菜单逐项接线并回归。

## 已定决策（禁止重新调研/讨论）

- 核心 = libghostty-vt（b0947378 pinned）；渲染器 = Rust + wgpu；会话层阶段一 Termux Java 不动（只换字节交付点）
- UI 只对着 CoreAdapter 缝写（ADR-0003）；XML/经典 View 壳（ADR-0001）；渲染驱动 = 独立渲染线程 + mailbox（工单 12）
