## 已定决策（禁止重新调研/讨论）

- 彩色字形通路 = **FreeType**（Ghostty 官方同款）；不换 Android Paint/JNI、不写纯 Rust paint graph、不押 taetype（观察项）
- 字体 = 内嵌 `NotoColorEmoji.ttf` **COLRv1 完整版**（Unicode 17.0，10.7MB，OFL-1.1）；替换 2017 CBDT；真机验收通过后移除旧字体
- ✅ 接受 COLRv1 原生彩色绿勾，不做灰勾覆盖
- ZWJ（家庭/肤色/旗帜）随 rustybuzz 整形一并解决
- 灰度正文保持 fontdue 不动；FreeType 只接彩色字形
- 下划线并入本单；图集增量上传 / 灰度迁 FreeType / taetype 评估不做（backlog）

- 仓库：spike-render（独立 git 仓库，`$HOME/CODEX/Fable/spike-render`）；fable-app（`$HOME/CODEX/Fable/fable-app`，.so 落 `app/src/main/jniLibs/arm64-v8a/libfable-render.so`）
- 构建：`cd spike-render && cargo build --release`（宿主自检）；交叉编译 `cargo build --target aarch64-linux-android --release`；APK：`cd fable-app && export JAVA_HOME=/data/data/com.termux/files/usr/lib/jvm/java-25-openjdk && ./gradlew :app:assembleDebug`

- 工具链：rustc 1.97.1 + rust-std-aarch64-linux-android 同步；Termux clang 21.1.8（默认 target `aarch64-unknown-linux-android24`）；宿主 freetype 2.14.3 + harfbuzz 14.2（离屏参照/自检）
- 现有彩色通路：`spike-render/src/emoji.rs`（CBDT 提取）；灰度 `fontdue`；sprite/下划线 `symbols.rs`（程序化矩形，SGR 4 已画）；`spike-render/assets/NotoColorEmoji.ttf`（2017 CBDT 5.3MB）+ `NOTO-EMOJI-LICENSE.txt`
